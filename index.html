Bring your own key — optional, never stored

Generate the principal-investigator briefing no key needed for the demo

The science above runs with no key at all. If you want an LLM-written briefing of this run, paste your own key. It is sent once, in the request body, to a function that uses it for a single Mistral call and then discards it. It is never written to Vercel's environment, never stored on disk, never logged, never put in a URL or a header, and never returned to this page. It lives in sessionStorage — closing the tab erases it.

Because this is bring-your-own-key, the key travels your browser → the Vercel function → your provider. It is never an environment variable on the server, so there is nothing for us to leak or rotate. The one honest caveat: the function sees it in memory for the duration of one request.

Governance

Two of the four experiments are refutations and both are reported. A lab that only reports successes has not run an experiment. The next experiment is a wet-lab LasR luciferase assay and it is blocked pending human approval — the safety agent routes it and does not let any agent simulate having done it.

What is not claimed

  • No docking, no affinity, no IC50. 2D proximity + property screening only.
  • No wet-lab validation. Direct signal quenching is unmeasured.
  • Controls are held out — scored after ranking is frozen, never a feature, threshold or weight.
  • Control set is small: 8 positive, 6 negative. Read the denominators, not the ratios.
  • The panel is ~60 compounds, an embedded offline subset — not the full ~1,600 approved space.
  • The speedup is descriptor computation and parallelism, not model reasoning.
  • All hypotheses, weights, gates and control sets are agent-generated and labelled as hypotheses.
