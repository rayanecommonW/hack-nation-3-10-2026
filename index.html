Six AI agents, working one scientific question

Agentic AI for scientific discovery

Bacteria coordinate an infection by releasing a chemical signal that tells other cells to start attacking. Six AI agents screened 60 approved drugs against that molecule, and narrowed the list to the 7 most worth taking to a lab.

Everything here was computed. No drug was tested at a bench, and no binding was measured, so the output is a shortlist of candidates rather than a discovery.

The question

Why block the signal instead of the growth

Bacteria do not attack alone. Pseudomonas aeruginosa, which causes lung infections in people with weakened lungs, releases a chemical signal that tells its own cells to switch on the genes that do the damage. Biologists call this process quorum sensing. The signal is a molecule named PQS.

A drug that blocked PQS would leave the bacteria unable to organise an attack. That is more interesting than an antibiotic, which kills the bacteria and therefore creates selection pressure for resistance. A drug that only blocks the signal is expected not to. That expectation is a theory rather than an established fact, and testing it needs real laboratory work this project has not done.

The agents

What each agent decides

An agent here is a separate AI role with one job and a written rule about what it may and may not do. Six of them split the work, and each one passes its findings to the next in a structured format. A software framework called Omnigent runs them.

How it works

How the system works

The system is deliberately unglamorous. One agent picks a test, another runs it and stays silent about what it means, and a third tries to prove the answer wrong. Then it repeats until something survives.

01
A person writes the question
The question and what would count as an answer are fixed before any agent starts. No agent is allowed to change them, so everything that follows is a search for evidence about one fixed question.
02
Gather cited evidence
Literature fans out to three retrieval agents in parallel, against PubChem, Europe PMC and OpenAlex. A fact with no locator is not admissible, and an agent's own inference is filed as a hypothesis rather than evidence.
03
Write down what would prove each idea wrong
Three possible explanations are written down in advance, each paired with the result that would disprove it. Because they were committed to before any data existed, the two failures later on this page are meaningful.
04
Pick which test to run next
The planner compares the options by how much each would teach, how likely it is to work, and what it costs, then picks the best one that fits the budget. Expensive steps wait for a human.
05
Run the test
Cheminformatics software calculates each compound's shape and physical properties, unsuitable ones are filtered out, and what survives is ranked. This agent is only allowed to return the numbers, never an opinion.

H2 is the mechanism switch that rescued the run after the fingerprint screen returned nothing. The weights sit in one dict above the function so a reader can object to a number without reading the algorithm.

06
Try to prove the result wrong
A separate critic checks the answer against drugs whose behaviour is already documented, confirms from the source code that those drugs never influenced the ranking, and returns one of three verdicts: refuted, inconclusive, or supported.

Thresholds are set before any result exists. H1 and H2 both fell below 0.2 recall, which is why two of the four rows on this page say refuted, and why that word is worth reading.

07
Accept or reject, and name the next step
A result is accepted only if it cleared fixed thresholds and the safety review passed. The decision is written down along with the next experiment and the result that would disprove it.

Engineering notes

Decisions worth arguing about

Some of these were forced by the hosting platform, some were judgement calls, and a couple are the kind of thing a reviewer should argue with.

The first search returned nothing at all. Why is that not treated as a genuine answer?
Because AUC across the full ordering was 0.77 while the top of the shortlist was empty. That is the signature of a tool failing rather than a hypothesis failing: the ranking carries signal, the gate is throwing it away. PQS is a plain chain of twelve carbon atoms and no approved drug resembles it closely enough, so a fingerprint cannot express the property that matters, which is that PQS is secreted as a surface-active species and quenching it is a physics problem.
The test drugs were kept out of the ranking. How can anyone be sure they did not sneak in?
They are scored only after the ranking is frozen, and the critic is required to verify from the source that no positive control appears in any score, threshold, tier rule or weight. If one does, the run is void rather than reported. It is the failure mode that would make every other number on this page worthless, so it is the one thing checked twice.
Part of the final score comes from published research rather than from data. How much does that part decide the answer?
More than I would like, and the leave-one-term-out ablation is published so you can discount it. Dropping the mechanism-prior term takes the top-ten positives from six down to two. That term comes from published work on drug families already reported to interfere with this signalling. It is not learned from the data here, but a reader is entitled to treat it as a thumb on the scale.
The screening software does not run on the live website. Is this page just replaying a stored file?
Yes, and the page says so rather than claiming otherwise. The drug search is done by RDKit, a chemistry library that takes 265 MB once installed. This hosting platform refuses anything over 250 MB, and when a build is too large it quietly drops the whole backend while the page still loads, so the failure only appears when something calls the API. The live site therefore reads a stored results file, and running the repository on your own machine recalculates it. Both routes give the same numbers.
Why does the website set almost none of its own response headers?
Because it kept setting Content-Length and the WSGI server was setting it too. Chrome rejects a response with two of those outright rather than tolerating it, so the page failed to load its own stylesheets. It is a small thing that cost real time and is the kind of bug that only shows up in a browser.
Why can a visitor not run this themselves on the page?
There was, briefly. Visitors pasted their own model key and the server called a provider on their behalf. It needed no key to work and no server secret, which was the right architecture, but it made a portfolio project depend on an open proxy to somebody's account. A recorded run with an honest funnel is the more durable artefact, so the page is now read-only and accepts no credential at all.

Limits

What this does not show

Stated plainly, because a reader who has been told the caveats can weigh the result properly, and a reader who has not will simply believe too much.

  • 01Nothing was measured in a laboratoryNo compound was tested against real bacteria. Whether any of them blocks the signal is unknown, and that is the only question that matters.
  • 02Eight positives is a small sampleRead the denominators rather than the ratios. Six of eight controls in the top ten is a useful signal, not a performance estimate.
  • 03Part of the score comes from published researchOne term rewards drug families already reported to interfere with this signal, and it decides most of the outcome. Removing it takes the known cases found from six down to two.
  • 04Sixty compounds, not sixteen hundredThe panel is an embedded offline subset chosen for reproducible offline scoring. The full approved space was out of reach.
  • 05The speed number is about computing, not thinkingIt measures how fast formulas can be run, not how good the reasoning is. One person could check a list this size in an afternoon.
  • 06The hypotheses are this lab's ownThe weights, the gates and the control sets were generated, not taken from a published model. They are hypotheses and are labelled as such.
What would make this 10 times faster for real. At ten thousand to a million drugs, the bottleneck stops being running the formulas and becomes running them across many machines at once, plus replacing the cheap shape comparison with real molecular modelling. That is the version of this work worth building, and none of it needs a better AI.
